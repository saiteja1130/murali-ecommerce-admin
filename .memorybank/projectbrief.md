# Project Brief: Admin Dashboard (murali-ecommerce-admin)

## 1. Overview
Merchant and administrator portal for catalog and store management.
- **Framework**: React + Vite
- **Styling**: TailwindCSS
- **Port**: `5173`
- **Backend Service**: Connects to `http://localhost:5000`

## 2. Key Pages & Features
- **Dashboard**: Store sales analytics, order volume, low stock notifications.
- **Products**: Data table with search, category filtering, multi-image upload, stock toggle, and price management.
- **Categories**: Department & Subcategory management with image upload.
- **Orders**: Order status management (Pending, Processing, Shipped, Delivered, Cancelled).
